# Wanderlust

Wanderlust is a full-stack travel listing application built with Node.js/Express on the backend and React/Vite on the frontend.

## Features
- Browse travel listings
- Create and edit listings
- User authentication and email verification
- Reviews and ratings
- Interactive map integration

## Tech Stack
- Backend: Node.js, Express, MongoDB, Cloudinary
- Frontend: React, Vite, Tailwind CSS

## Getting Started
1. Clone the repository
2. Install backend dependencies:
   ```bash
   cd backend
   npm install
   ```
3. Install frontend dependencies:
   ```bash
   cd ../frontend
   npm install
   ```
4. Start the development servers

## Notes
Make sure to configure your environment variables in the backend .env file before running the app.
